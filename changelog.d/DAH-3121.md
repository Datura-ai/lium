### Changed
- CLI crash reports (opt-in, DAH-2057) now reach the `lium-cli` Sentry project: the client key ships in the CLI (`LIUM_SENTRY_DSN` overrides it; empty disables), the environment is derived from the API host (`lium.io` → production, a staging host → staging), and each event carries `cli_version`, `api_host` (host name only) and `error_class` tags. Home directories on macOS, Linux and Windows (usernames with spaces or apostrophes included), e-mail addresses, API keys, SSH keys and the values the command was given are cut out of the message; the message is capped at 4,096 characters. (DAH-3121)
