### Added
- `lium mcp`: an MCP server over stdio so an agent host (Claude Desktop, Claude Code, Cursor) can list GPUs, rent a pod, run commands on it, remove it and read the balance. Install with `pip install 'lium.io[mcp]'`; rentals it makes carry `X-Source: mcp`.

### Changed
- SDK `Lium.up`: when the rent request gets no answer and the repeat fails or is refused, it raises `LiumRentOutcomeUnknownError` (a `LiumError`, with `idempotency_key`, `pod_name`, `executor_id`). Before, it raised whatever the repeat raised. A pod may exist in that case, so check `lium ps` before renting again.
