### Added
- `lium mcp`: an MCP server over stdio so an agent host (Claude Desktop, Claude Code, Cursor) can list GPUs, rent a pod, run commands on it, remove it and read the balance. Install with `pip install 'lium.io[mcp]'`; rentals it makes carry `X-Source: mcp`.

### Changed
- SDK `Lium.up`: when the rent request gets no answer and the repeat fails or is refused, it raises `LiumRentOutcomeUnknownError` (a `LiumError`, with `idempotency_key`, `pod_name`, `executor_id`). Before, it raised whatever the repeat raised. A pod may exist in that case, so check `lium ps` before renting again, or pass the error to the new `Lium.replay_rent`, which re-sends the request with the same key and returns the pod the API made. It raises a plain `LiumError` only for the API's stored refusal of the first request (`Idempotent-Replayed: true`); anything else stays `LiumRentOutcomeUnknownError`.
- SDK `Lium.up` takes `idempotency_key=` (to send a key you choose) and `confirmed_only=True` (never return a pod matched only by name, which may be another client's; raise `LiumRentOutcomeUnknownError` with it in `candidates` instead) and `before_send=` (called with the endpoint, payload and key right before the first request, to journal it; if it raises, nothing is sent).
