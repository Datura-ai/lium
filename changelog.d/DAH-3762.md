### Added
- `lium topup card -a <USD> [--card <pm_id>] [--idempotency-key <key>] [--yes] [--json]` — charge a card saved on the account from an API key with the `billing` scope, no browser (not released: the platform switch is off). The command asks before charging; `--yes` skips the question and `--json` needs it. Sent once with an idempotency key; a lost answer or a 202 still-confirming exits 6 (`charge_outcome_unknown` / `charge_pending`) with the key to re-run with. SDK: `Lium.topup_card(amount_usd, payment_method_id=None, idempotency_key=None)`; `LiumCardTopUpError` for the route's 402s, `LiumChargeOutcomeUnknownError` for a lost answer.
