### Added
- `lium completion [bash|zsh|fish] [--install]` prints the shell line that enables tab completion (default) or appends it to the shell's rc file once.

### Changed
- The silent first-run installation of shell completion only happens when a person is at a terminal; scripts, CI jobs and agents no longer get their rc files edited as a side effect. Use `lium completion --install` to opt in.
