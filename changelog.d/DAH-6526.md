### Fixed
- `lium mine` no longer stops when apt/dpkg is busy before the Sysbox install (right after a boot this is usually unattended-upgrades). It waits up to 15 minutes for the lock, and names the holder only if it is still held after that.
- `lium mine` no longer asks for `newgrp docker` and a re-run when its own install just added the user to the docker group. It re-runs the same command once under `sg docker`. Users outside the group, hosts without `sg`, or a second attempt still get the `newgrp docker` message.
- A `lium mine` re-run on an installed node keeps the hotkey saved in its `.env` when `-k` is not given. After `--register` that hotkey is the portal's, which the provider never typed, so `lium mine --auto --renting-port-range 40000-40100` now changes only the range.
