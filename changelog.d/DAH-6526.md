### Fixed
- `lium mine` no longer stops when apt/dpkg is busy before the Sysbox install (right after a boot this is usually unattended-upgrades). It waits up to 15 minutes for the lock, and names the holder only if it is still held after that.
- `lium mine` no longer asks for `newgrp docker` and a re-run when its own install just added the user to the docker group. It re-runs the same command once under `sg docker`, both when its install step exits on the new group and when the later Docker check is denied. Users outside the group, hosts without `sg`, or a second attempt still get the `newgrp docker` message.
- A `lium mine` re-run on an installed node keeps the hotkey saved in its `.env` when `-k` is not given. After `--register` that hotkey is the portal's, which the provider never typed, so `lium mine --auto --renting-port-range 40000-40100` now changes only the range.

### Added
- `lium mine --register` shows the portal's own outside check of the node's service port right after the node is added. When the port did not answer, the provider sees which address and why at once, instead of after the listing wait times out.
- `lium mine --storage file|DISK`: when Docker cannot cap a container's disk yet, it sets up Docker storage on xfs with pquota without asking, also under `--register`. `file` creates an XFS image file on the host's disk. A disk path formats that spare disk, and only one the setup lists as spare. The flag is off by default.
- `lium mine --host-tuning`: turns on NTP (`timedatectl set-ntp true`) and holds the installed NVIDIA, Docker and containerd packages (`apt-mark hold`, as in the troubleshooting guide). The flag is off by default.
