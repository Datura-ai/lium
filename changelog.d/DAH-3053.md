### Changed
- `lium ls` (and `Lium.ls()`) requests `GET /executors?view=summary` and no longer sends a bare `size=1000`, which made the API rebuild the listing per call instead of serving its 5-second cache. lium.io answers `view=summary` with the listing fields only, about 1 KB per node instead of about 8.6 KB; the Link fields (`link`, `nvlink`, `p2p`, `interconnect`) on that view need lium-platform#522 deployed and are `null` until then. `Lium.ls(view="full")` keeps the whole validator scrape in `ExecutorInfo.specs`.
- The CLI starts faster: `paramiko` and the host-key policies (`lium/sdk/_hostkeys.py`) load on the first `ssh_connection()`, and the `provider` command group loads on first use (`import lium.cli.cli` about 0.42 → 0.22 s p50 on a pod). `lium.sdk.client.paramiko`, `host_key_fingerprint`, `_PinOnFirstUsePolicy` and `_InsecureAcceptPolicy` still resolve; host-key pinning (DAH-2904) is unchanged.
