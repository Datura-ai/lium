### Changed
- `lium ls` (and `Lium.ls()`) requests `GET /executors?view=summary` and no longer sends a bare `size=1000`, which made the API rebuild the listing per call instead of serving its 5-second cache. Today's API returns the full row for every view; lium-platform#216 (not released) answers `view=summary` with the listing fields only, about a tenth of the size. `Lium.ls(view="full")` keeps the whole validator scrape in `ExecutorInfo.specs`.
- The CLI starts faster: `paramiko` and the host-key policies (`lium/sdk/_hostkeys.py`) load on the first `ssh_connection()`, and the `provider` command group loads on first use (`import lium.cli.cli` about 0.42 → 0.25 s on a pod). `lium.sdk.client.paramiko`, `host_key_fingerprint`, `_PinOnFirstUsePolicy` and `_InsecureAcceptPolicy` still resolve; host-key pinning (DAH-2904) is unchanged.
