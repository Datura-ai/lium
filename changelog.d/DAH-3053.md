### Changed
- `lium ls` (and `Lium.ls()`) requests `GET /executors?view=summary` — the fields a listing reads, about a tenth of the full row — and no longer sends a bare `size=1000`, which made the API rebuild the listing per call instead of serving its 5-second cache. `Lium.ls(view="full")` keeps the whole validator scrape in `ExecutorInfo.specs`.
- The CLI starts faster: `paramiko` is imported by `ssh_connection()` only and the `provider` command group loads on first use (`import lium.cli.cli` 145 → 80 ms on a Mac, 534 → ~360 ms on a pod); `lium.sdk.client.paramiko` still resolves.
