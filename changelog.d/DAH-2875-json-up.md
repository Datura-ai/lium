### Added
- `lium up --json` prints the ready pod as one JSON document on stdout (`{"pod": {…}}`, plus `termination_time` when `--ttl`, `--until` or the `--budget` cap set one; `pod` has the keys of a `lium ps --format json` row) and ends there instead of opening SSH or streaming logs. Progress lines and the price prompt go to stderr. A failure after the rent (`pod_not_ready`, `pod_start_failed`, `gpu_count_mismatch` with `data.pod_removed` under `--strict-gpus`, `gpu_verification_failed`, `jupyter_install_failed`, and an API error or a lost connection (`api_timeout`) during the wait, the `--ttl` retry or the Jupyter install) carries the billing pod in the envelope's `data.pod_id` / `data.pod_name`. When `--volume new:` created a volume, `timeout_before_rent` and the failures at the rent (`api_timeout`, `rent_rejected`, an API error) carry it in `data.volume_id` / `data.volume_huid` and say the volume is kept. With `--jupyter`, `pod.jupyter_url` is the URL the install produced. The teardown half is `lium rm --format json` (0.2.0).
