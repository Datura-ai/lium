### Fixed
- `lium gpu-splitting check` / `setup` (and `lium mine`'s Docker storage step) no longer hang in step [2/2] "Resolving target". `parted` now runs in script mode (`-s`): without it, `parted` could stop to ask a question on some disks (seen on a VM) and wait forever behind the spinner. No planning command reads the terminal any more. Each planning command has a deadline (120 s; `du` of the Docker root gets 1 h), and a command that runs past it fails with a message naming it. The step line shows which command is running.
- `lium gpu-splitting check` / `setup` and `lium mine`'s Docker storage step now stop at once on a container (`systemd-detect-virt -c`, `/.dockerenv` or `/run/.containerenv`) and say that a Lium node must be a full VM or bare metal. Disks that `lsblk` lists without a `/dev` node (a container sees the host's disks that way) are no longer inspected or offered.
