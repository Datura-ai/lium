### Added
- `lium exec --detach/-d` starts the command in the background on the pod (`nohup setsid bash -lc ... < /dev/null &`), prints its PID and log path, and returns immediately. `--log PATH` overrides the default `/workspace/logs/exec-<timestamp>-<id>.log` (the id keeps two jobs started in the same second apart). The launcher checks that `setsid` and `bash` exist on the pod before forking, so a pod without them reports a failed start instead of a PID. The launcher line lives in `lium.sdk.detach` so the SDK's detached exec shares it. With `--script` the script is copied to the pod first and then started detached. `--json` reports `pid`, `log` and `error` per pod.
