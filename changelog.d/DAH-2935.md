### Fixed
- `lium provider status`, `lium provider node list` and `lium provider billing list` now scope the portal's global listings to the active hotkey, so a provider sees only its own nodes and charges (previously other providers' machines were reported as the caller's). `node list --all` / `billing list --all` return the unfiltered listing; `--miner-hotkey` still targets one provider. When the hotkey's ss58 cannot be resolved (no local wallet), `node list`/`billing list` refuse with `ARG_INVALID` and `status` skips the node count with a warning instead of reporting everyone's nodes. (DAH-2935)
