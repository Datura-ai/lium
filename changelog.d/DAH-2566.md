### Fixed
- `lium ps --format json` and `lium describe` (table and `--json`) show `ssh_command`: the pod's ssh command with the pinned host-key options `lium ssh` uses (`-o StrictHostKeyChecking=accept-new -o UserKnownHostsFile=~/.lium/known_hosts/<pod-id>`, DAH-3215/DAH-2904), so a command copied from them keeps working after a pod restart made through the CLI or SDK (the pin is dropped, ssh re-pins) as long as the pod's host and port did not move; both JSON views keep the API's raw value as `ssh_cmd`. Building it creates `~/.lium/known_hosts/` but no per-pod file.

### Added
- `Lium.refresh_pod(pod)` re-reads one pod (a `PodInfo`, an id or a huid) from the API and raises `LiumNotFoundError` when it is gone; `Lium.ssh(pod, refresh=True)` builds the command from the pod's current host and port instead of the ones in a `PodInfo` fetched earlier.
- `lium.sdk.pod_ssh_command(pod)`: that command for callers that build their own output; `openssh_host_key_options(pod, create_pin_file=False)` returns the options without touching the pin file.
