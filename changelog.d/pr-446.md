### Fixed
- `lium fund`, `lium fund --alpha` and `lium fund --gamma` no longer hang after the wallet password on
  bittensor 11. The transfer is signed with the key the password already unlocked; before, bittensor asked
  for the password a second time behind the progress spinner, so the command sat there and sent nothing.
- The standalone binary can run `lium fund --gamma`: it now carries the chain type registry, without which
  the quote failed with `Decoder class for "MetadataVersioned" not found`.
