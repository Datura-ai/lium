### Changed
- `lium keys create` and `ApiKeysClient.create` accept `billing` next to `read`, `rent` and `manage`, so one key can rent pods and pay. This needs a newer Lium server: an older one answers 422 and makes no key. Before, the CLI and SDK refused it before any request (exit 2). `billing` alone still makes a key that reaches only the money routes. `lium.sdk.api_keys.BILLING_ALONE` is removed.
