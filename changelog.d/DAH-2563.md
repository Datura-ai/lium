### Added
- SDK: background jobs. `Lium.run_background(pod, command, name=)` starts a command under `nohup setsid` with a PID file, an exit-code file, a log and an identity file (boot id + process start time, so a PID reused after a pod restart is not taken for the job; a job with no identity file reads `gone`, is not signalled by `kill()` and does not block a new start under its name) under `/workspace/logs/<name>.*` and returns a `Job`; `job.wait_for_port(port, timeout)` polls the port inside the pod and fails at once (with the log tail) if the process dies first; `job.status()`, `poll()`, `wait()`, `logs(tail=)`, `kill()`; `Lium.job(pod, name)` re-attaches from another process or a later agent turn, `Lium.jobs(pod)` lists them. `Lium.wait_for_port(pod, port)` probes a port on its own and `Lium.wait_ready(..., ready_port=N)` waits for RUNNING *and* the port.
