### Fixed
- `lium config set template.default_id` lists templates again: the interactive picker called `Lium.list_templates()`, a method the SDK does not have, and always failed.
- `lium ls` / `Lium.ls()` no longer abort on a marketplace record with an empty, blank or missing `machine_name` (the GPU type then comes from the listed GPU names, or reads `Unknown` when there are none), or with `specs` / `specs.gpu` set to null.
- An executor's GPU count is the record's top-level `gpu_count` (the count you are billed on), then `specs.gpu.count`, then the number of listed GPUs; a missing count no longer shows an 8-GPU node as `1×` at a 1-GPU price, and a count sent as a string is parsed instead of raising.
