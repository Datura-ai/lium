### Changed
- `lium rm` without `--yes` now fails when stdin is not a terminal (or `LIUM_NONINTERACTIVE=1`) — for named pods and lists as well as `--all` and row numbers. It names the pods it would have removed and the same command with `--yes`, exits 2 (`confirmation_required`), and removes or schedules nothing. A piped answer is no longer approval: `echo y | lium rm my-pod` exits 2 where it used to remove the pod; scripts pass `-y`. On a terminal nothing changes.
