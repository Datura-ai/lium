### Changed
- `@lium.machine`: on a backend that advertises `rent_by_spec`, a cold call rents through `Lium.rent` — one `POST /executors/rent-by-spec` that picks the cheapest node of the requested count and type and rents it (falling through to the next candidate if the pick is taken meanwhile) — instead of listing all executors three times (`ls`, then `Lium.up`'s `get_executor` and `default_docker_template`; ~2.2 s each). The progress line becomes `rented 1xA100 $1.20/h (...)` and the cost line uses what the rental bills. Against an older backend the listing path is unchanged. (DAH-3047)
