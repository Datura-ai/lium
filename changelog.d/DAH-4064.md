### Added
- `lium mcp`: an MCP server over stdio so an agent host (Claude Desktop, Claude Code, Cursor) can list GPUs, rent a pod, run commands on it, remove it and read the balance. Install with `pip install "lium.io[mcp]"`; rentals it makes carry `X-Source: mcp`.
- `lium mcp` is published to the official MCP Registry as `io.github.Datura-ai/lium` after each PyPI release, and runs without an install as `uvx --from "lium.io[mcp]" lium.io mcp` (new `lium.io` command, same as `lium`).
- `lium mcp`: `list_gpus` shows each node's reliability score and `rent_price_per_hour_usd` (what `rent_pod` bills for the free GPUs); `rent_pod` takes the id or rent link that docs.lium.io/mcp `search_gpus` returns, and `dry_run: true` quotes tier, reliability, cost per hour and your balance without renting. SDK `ExecutorInfo.reliability_score`.

### Changed
- SDK `Lium.up`: when the rent request gets no answer and the repeat fails or is refused, it raises `LiumRentOutcomeUnknownError` (a `LiumError`, with `idempotency_key`, `pod_name`, `executor_id`). Before, it raised whatever the repeat raised. A pod may exist in that case, so check `lium ps` before renting again.
- SDK `Lium.up` takes `idempotency_key=` (to send a key you choose) and `confirmed_only=True` (never return a pod matched only by name, which may be another client's; raise `LiumRentOutcomeUnknownError` with it in `candidates` instead) and `before_send=` (called with the endpoint, payload and key right before the first request, to journal it; if it raises, nothing is sent).
- SDK `Lium.features()`: a `/version` that cannot be reached is no longer cached as "no features"; it is asked again on the next call.
