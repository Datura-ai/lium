### Fixed
- `lium up` waits for the pod's SSH port to answer with an SSH banner, for up to 60 s, before it opens the session. A pod reports RUNNING before an sshd started by the image is listening, and the single ssh attempt used to fail with `ssh_connection_failed`. If the port still doesn't answer after 60 s, ssh is tried once anyway. When that attempt fails too, the error says the SSH port never answered, and the `--json` envelope carries `pod_id`, `pod_name`, `ssh_port_answered: false` and `ssh_wait` (host, port, attempts, last problem). The pod is not removed. `--json` and `--no-ssh` don't wait, because they open no session.
