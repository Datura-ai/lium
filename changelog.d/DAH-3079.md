### Changed
- `lium ls` default order is cheapest `$/GPU·h` first (was: ★ Pareto nodes first, then fastest download). Nodes without a price sort last. The ★ still marks Pareto-optimal nodes where they land; `--sort` overrides. Each row's `index` in `--format json` (and the number `lium up <index>` takes) moves with the new order. `lium up <index>` is numbered from the same order `ls` prints.
