### Fixed
- `@lium.machine`: whatever the function prints reaches the caller's stdout/stderr while it runs (it used to be captured by `Lium.exec` and thrown away), and stays on `RemoteExecutionError.stdout/.stderr` when the call fails. `Lium.stream_exec` gains `pty=False` to keep the two streams apart, returns the exit status as the generator's return value, and no longer spins a CPU core while waiting for output.
