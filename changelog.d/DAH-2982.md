### Added
- `lium rm` prints one line per removed pod with its uptime and estimated spend — `removed <name> — <uptime> at $X/h ≈ $Y` (uptime × list $/h; the API returns no billed figure; uptime spelled as in `ps`, e.g. `1.5h`) — and `--format json` returns the same fields (`uptime`, `uptime_hours`, `price_per_hour`, `spent_usd`, `spent_is_estimate`) for removed or scheduled pods. A partially failed `--format json` run still prints one parseable payload (with `failed`) and exits non-zero. (DAH-2982)
