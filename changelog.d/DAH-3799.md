### Added
- Pods reached through the Lium SSH gateway (`ssh -J jump@<gateway> root@<pod>.<domain>`, not served yet) work in `lium ssh`, `lium exec`, rsync/scp and SDK connections. The hop uses the same key, and the gateway's host key is pinned under `~/.lium/known_hosts/gateway-<host>` the way each pod's is. `lium cp` to such a pod says it is not supported yet instead of failing midway.
