### Added
- `lium request <GPU> --auto-rent --max-price USD --hours H -t TEMPLATE [--start-after/--start-before UTC]` and the matching `Lium.request_machine()` arguments: the server rents the cheapest node that matches the request inside the window, at or below the price, for the hours given, with the configured SSH keys. It needs a paid top-up and the personal workspace, and an API key needs the `rent` scope. The CLI refuses `--auto-rent` without `--count`, `--max-price`, `--hours` and `--template` before any request (exit 2). Needs a newer Lium server.
