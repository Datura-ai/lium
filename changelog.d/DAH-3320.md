### Added
- `lium mine --register <TOKEN>`: one command from a bare host to a node listed in the provider portal. The token is the one the portal's Add Node page prints next to the command (valid one hour). After the executor is up and validated, the node is added to your account with the GPU model and count `nvidia-smi` reports, this host's public IPv4 and the executor's own port, at the model's base price from lium.io's public shared-config (`--price` overrides; `--gpu-type` registers under another portal GPU name, for when the portal does not know the reported one); then its status is polled every 15 s until it is listed (exit 0), the portal names something to fix — OFFLINE or VALIDATION_FAILED with the portal's own text (exit 1) — or `--wait` minutes pass (exit 2, default 45). `--register` implies `--auto`; the account and the value the node reports under come from the token, so `-k` is not needed — an account created with e-mail or Google has no key of its own; the portal's key, carried by the token, is what lands in the executor's `.env`. `--portal-url` / `LIUM_PORTAL_URL` select another portal. A bad or expired token is refused before the install starts; a node already in the portal at the same address is not an error — its status is what gets watched.
