### Added
- CLI: `lium provider machine-request list` renders the portal's aggregate tier — one count table per GPU class and per hourly budget band (`<$1/h`, `$1-3/h`, `$3-10/h`, `$10+/h`, `unknown`) — and says why there are no per-request rows. The portal answers that shape until one of the hotkey's nodes is verified by a validator; `--json` passes the object through under `data`.

### Changed
- A `403` from the provider portal is reported as `PORTAL_FORBIDDEN` instead of `PORTAL_AUTH_INVALID`; the exit code is unchanged (2) and the hint no longer tells the user to re-login, because the token is fine. `lium provider machine-request get <ID>` answers that way until one of the hotkey's nodes is verified.
