### Fixed
- `--gpu 4090` (a bare model number), `--gpu "rtx 4090"` and other spacing/case variants now find the RTX 4090 nodes instead of matching nothing; `--gpu 6000` returns every 6000-class node (RTX 6000, RTX PRO 6000, A6000). When the value names no GPU type at all, `lium ls` — and `lium up` against a backend without rent-by-spec; a rent-by-spec server answers with its own no-match message — say "No GPU type matches" and list the marketplace's types instead of claiming every such GPU is rented out. SDK: `gpu_short_matches()`, `Lium.gpu_short_types()`, `Lium.unknown_gpu_type()`.
