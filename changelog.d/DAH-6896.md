### Fixed
- `lium provider` commands that cannot open the wallet (`WALLET_NOT_FOUND`) now say why: the message carries the underlying error, which names the keyfile path that was read and whether it was missing, unreadable or encrypted. Before, only the wallet and hotkey names were shown.
- A hotkey file that is password-encrypted and does not decrypt now gets its own hint (check the password; a file encrypted by a newer bittensor-wallet fails the same way) instead of "create a wallet".
