### Added
- `lium transfer <email|user-id> <amount> [--note TEXT] [--yes] [--json]` and `Lium.transfer_credits(to, amount,
  description=None, idempotency_key=None)` send part of the balance to another account through
  `POST /users/me/transfer-credits` (a `billing`-scope key). The CLI asks first (`--yes` skips it; `--json` needs
  it); the SDK sends an `Idempotency-Key` header. Errors exit non-zero with the API's code (`self_transfer`,
  `insufficient_balance`, `not_found` for no such account, `recipient_unavailable` for a deleted or blocked one); a key without `billing` gets `missing_scope` and how to make one. A lost answer (timeout, dropped
  connection, 5xx, Ctrl-C, or the server's `idempotency_outcome_unknown` / `idempotency_in_progress`) exits 6 with `transfer_outcome_unknown` and the
  key; check the Billing page of the account owning the billing key and, if no such transfer is there, contact
  support with the key. It is never re-run. The amount is rounded to the cent, as the API does, before it is confirmed.
