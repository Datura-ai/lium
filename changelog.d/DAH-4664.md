### Added
- `lium transfer <email|user-id> <amount> [--note TEXT] [--yes] [--json]` and `Lium.transfer_credits(to, amount,
  description=None, idempotency_key=None)` send part of the balance to another account through
  `POST /users/me/transfer-credits` (a `billing`-scope key). The CLI asks first (`--yes` skips it; `--json` needs
  it); the SDK sends an `Idempotency-Key` header. Errors exit non-zero with the API's code (`self_transfer`,
  `insufficient_balance`, `recipient_unavailable`); a key without `billing` gets `missing_scope` and how to make one. A lost answer (timeout, dropped
  connection, 5xx, or the server's `idempotency_outcome_unknown`) exits 6 with `transfer_outcome_unknown` and the
  key; check the Billing page of the account owning the billing key and re-run only if no such transfer
  is there, with `--idempotency-key <key>`. The amount is rounded to the cent, as the API does, before it is confirmed.
