### Fixed
- `lium up` with filters (`--gpu`, `--count`, `--country`, `--ports`) now rents, instead of the first node the API returned, the Pareto-optimal node with the lowest total `$/h` for what the rent takes (`--count` GPUs, else the node's free GPUs, at that node's `$/GPU`); the frontier is drawn among nodes renting the same count, so a cheaper-per-GPU 8× node neither beats nor hides an otherwise equal 1× node; it prints the selected node and its total `$/h` before renting, and the help text says so. Explicit `NODE_ID` picks are unchanged. (DAH-2980)
