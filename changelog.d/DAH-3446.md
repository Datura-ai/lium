### Security
- SDK: `Lium.ssh_connection` (the paramiko path behind `exec`, `exec_all`, `stream_exec`, `scp`, `upload`, `download`, `ssh_session` and, through them, `cp`) accepts only `ssh <user>@<host> [-p <port>]` from the API's `ssh_cmd`, the check `ssh_argv` and `lium ssh` already apply (`ssh_target`). Any other shape is a `ValueError` before a connection is opened, instead of the hand-split user, host and `PodInfo.ssh_port`. `cp` tells the source pod the same validated user, host and port for its hop to the destination.
