### Added
- `lium up --verify-gpus --json` carries the passed check's counts as `gpu_verification` (`expected`, `billed`, `visible`).

### Fixed
- `lium volumes rm` takes a volume HUID or id as well as a row number of the last `lium volumes` list; a HUID needs no prior list.
- `lium bk show` prints the path a default backup covers (the pod's volume, `/root`) instead of a blank `path=`.
- A `--gpu` whose nodes offer none of the requested GPU count (`rentable GPU counts: 6, 8`) now ends with the next step in `lium up` and `lium job run`, e.g. `Use --count 6 (on offer: 6, 8), or another --gpu` (`job run --format json` keeps its result unchanged).
- The first SSH connection to a pod no longer prints `UserWarning: ... Permanently added ...` and `Pinning ... host key` tracebacks; under `LIUM_SSH_INSECURE=1` ssh's notice that verification is off still shows.
- `lium ps` stays readable at 80 columns and behind a pipe: the Ports column shows the SSH mapping and a count (`22:20301 +10`), and the fixed columns size to their content. `--format json` is unchanged.
