### Fixed
- `lium reset-gpu`: a reset the node refuses (`gpu_in_use_outside_pod`, `reset_not_supported`) no longer ends with "Retry; if it persists, re-run with LIUM_DEBUG=1". The `gpu_in_use_outside_pod` hint says to stop the named process if it is the renter's own and retry, otherwise to contact the provider; both hints point to picking a different node in `lium ls` and renting it with `lium up <node>`.
- `lium reset-gpu`: the `reset_not_supported` / `container_not_restarted` hint no longer says the node did not reset the GPUs, which is untrue when the GPUs were reset and only the container did not start again. The container warning says the reset did not start the container again instead of "is still stopped".
