### Fixed
- `lium reset-gpu`: a reset the node refuses (`gpu_in_use_outside_pod`, `reset_not_supported`) no longer ends with "Retry; if it persists, re-run with LIUM_DEBUG=1". The hint says a retry will not help a cause on the host and points to renting another node with `lium up`.
- `lium reset-gpu`: GPUs that were reset in a pod whose container then did not start again (`container_not_restarted`) get a hint about the container (`lium ps`, `lium reboot`), not one saying the node did not reset the GPUs. The warning for that case says the reset did not start the container again instead of "is still stopped".
