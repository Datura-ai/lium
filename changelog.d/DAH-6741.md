### Fixed
- `lium reset-gpu`: a reset the node refuses (`gpu_in_use_outside_pod`, `reset_not_supported`) no longer ends with "Retry; if it persists, re-run with LIUM_DEBUG=1". The hint says a retry will not help a cause on the host and points to renting another node with `lium up`.
- `lium reset-gpu`: the `reset_not_supported` / `container_not_restarted` hint no longer says the node did not reset the GPUs (each GPU's result says whether it was); a second run first tries to start a stopped container. The container warning says the reset did not start the container again instead of "is still stopped".
