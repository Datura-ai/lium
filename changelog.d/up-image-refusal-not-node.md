### Changed
- `lium up`: when the API refuses the image before renting (`image_not_found`, `image_needs_registry_credentials`, `image_registry_credentials_refused`, `image_no_linux_amd64`, `image_reference_invalid`), the error says the image was refused before any node was used, that no pod was created and that renting another node will not help, with the server's hint. It no longer says the node could not be rented or points at `lium ps` and `lium ls`. The same holds when `lium up --gpu` picks the node with a dry run: an image refusal there is no longer `node_selection_failed` with a `lium request` suggestion. The error code stays the server's.
