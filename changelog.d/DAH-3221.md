### Changed
- The Linux binary build jobs (`ci.yml`, `release.yml`) now report what the bundle ships — the Debian `libssl1.1` package version, the OpenSSL runtime string, the Python version and the bundled `requests` / `paramiko` / `cryptography` versions — in the run's step summary, and fail when `libssl1.1` is below `1.1.1w-0+deb11u8` or a bundled library is not the build image's file (`scripts/linux_bundle_report.py`). A release cannot publish a bundle that regressed the way 0.0.34 did.
