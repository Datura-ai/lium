### Changed
- SDK `Lium.up(executor_id=..., gpu_count=N)` on a node that rents whole only (`ExecutorInfo.whole_host_only`) raises `ValueError` "rents whole only. Request all N GPUs." when N is less than the node's free GPU count (the whole host), after reading the node listing and before sending the rent request; requesting all of them rents as before. This is the same check `lium up -c` has.
