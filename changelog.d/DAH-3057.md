### Added
- SDK exceptions carry the API's `code`, `hint` and `request_id` (from the error envelope or the `X-Request-Id` header); the CLI prints the hint and `request_id: …` under every API error (the rent refusal in `lium up` included) and, under `--json`, puts the server's code in `error.code`, its hint in `error.hint` (in place of the CLI's default) and `request_id` in `data`, so a failure can be quoted to support and keyed on by agents.
