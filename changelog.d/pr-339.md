### Changed
- `lium fund` reaches the pay API through the Lium API with your own API key; the SDK no longer carries a pay-API key.
  Needs a Lium API with the `/tao/pay` routes.

### Removed
- `Config.base_pay_url` and the `LIUM_PAY_URL` variable: the CLI no longer calls the pay API directly. `Config(base_pay_url=...)` now raises a TypeError.
