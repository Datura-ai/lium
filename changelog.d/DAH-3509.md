### Fixed
- `lium mine --register <TOKEN>` finds the node it just added and watches its status with the register token. Once lium-platform#458 deploys, the provider portal's node list without a token is a public projection with no address and a node's page needs a token; the token from the Add Node page opens both for the account's own nodes. The wait for the validator stops half a minute before the token expires and says where the status keeps updating. A portal from before the change ignores the token on both reads, so either portal works.
- `lium provider node list --all` reads the portal's public view without the session token: with it, the portal takes a list with no filter as your own nodes, so a signed-in `--all` returned only yours. Once lium-platform#458 deploys, `--all` and `--miner-hotkey` rows are the public shape (id, hotkey, GPU, price, tier, region, status, uptime); your own list stays the full rows.
