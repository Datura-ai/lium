### Added
- Experimental, off unless `LIUM_SECRETS_ENABLED=1`: `lium secrets set NAME` (value from stdin or a hidden prompt typed twice — a value on the command line is refused without being echoed), `lium secrets list` (names and update times, never values), `lium secrets rm NAME`, and `lium up --secret NAME` to deliver a saved secret as `/run/lium/secrets/NAME` in the pod instead of an environment variable. SDK: `Lium.secrets.set/list/delete` and `secret_names=` on `Lium.up` / `Lium.rent`. Every upload goes through `lium.sdk.secrets.encrypt_for_upload`, a no-op until client-side encryption lands; the server endpoints are not live yet. With the variable unset, help output and rent payloads are unchanged.
