### Added
- `lium provider node register-token`, `node tier eligibility|set`, `node pause|resume` and `node listing [NODE_ID]`: the portal's Add Node token, Secure/Spot tier, new-rental pause and listing state from the terminal.
- `lium provider earnings`, `idle-pay [NODE_ID]` and `ledger`: daily earnings (with `--emissions`), idle-pay state per node and the daily ledger.
- `lium provider portal login --email you@example.com` signs in without a wallet; the password comes from `LIUM_PROVIDER_PASSWORD` (a hidden prompt on a terminal).
- `lium provider token create|list|revoke`, and `LIUM_PROVIDER_TOKEN` is sent as the Bearer token when set. Until the portal serves API tokens the commands answer `portal.not_supported` (exit 3).
- `lium mine --json`: one JSON result on stdout, one JSON step event per line on stderr (`host.repo` … `host.validate`, `host.register`, `host.wait_listed`), failures with a stable `host.*` code (`host.port_in_use`, `host.docker_missing`, `host.preflight_failed`, …). `LIUM_OUTPUT=json` does the same.
- `docs/exit-codes.md` documents the provider exit map (0–7, 10 blocked, 11 not listed, 12 a person has to act) and which old codes the new ones replace.

### Changed
- `mine.sh` installs `lium.io[provider]`, so `lium provider …` works right after `lium mine`.
- `lium provider` answers `net.unreachable` (exit 4) instead of `PORTAL_SERVER_ERROR` when nothing answers at the portal URL, and passes a portal refusal's own `detail.code` through as `portal.<code>`.

### Fixed
- The provider persona gate no longer prompts under `--json` or without a terminal: it fails with `input.confirmation_required` (exit 2) and names `--yes` / `LIUM_PROVIDER_ACK=1`. EOF or Ctrl-D at the prompt is the same error instead of a traceback, and the acknowledgement is kept per user and config instead of per parent process, so an agent's next subprocess is not asked again.
- `lium mine` without a terminal and without `-k` exits 2 with `input.input_required` instead of an EOF traceback at the hotkey prompt; with `-k` it takes the default ports as `--auto` does.
