### Added
- `Lium.ssh_session(pod)`: a context manager that keeps one SSH connection open so every `exec`, `stream_exec`, `upload` and `download` inside the block reuses it. `@lium.machine` runs the upload, environment step, run and result download in one session — each of them used to open its own connection (four extra TCP + SSH handshakes per call, several seconds each on a distant node).
