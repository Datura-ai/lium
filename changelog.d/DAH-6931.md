### Fixed
- `lium mine -k <new hotkey>` on a running node now restarts the executor so it reports the new hotkey; before, a node moved to another account kept serving the old one and the portal refused `lium provider node add` with a hotkey mismatch. While a rental runs or is being created (the validator's SSH session in the executor is open) no re-run restarts the executor, for any changed setting; before, a re-run could cut a rental being created.
