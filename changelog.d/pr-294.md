### Added
- `lium provider node list`, `node get`, `node status` and `lium provider status` print a red BLOCKING panel for each node that is kept off the listing or out of idle pay: every reason with its measured and required value and `Fix: <what to do>`, then the Secure listing requirements the node does not meet. The node table shows such a node as `BLOCKED` instead of a green `AVAILABLE`, and `lium provider status` counts the blocked nodes at the top.
- `--json`: each node carries the same list under `blocking_reasons` (`node status` adds it to the verification object, `status` adds `blocked_node_count`). The CLI shows the portal's `blocking_reasons` as served; until the portal serves them it builds the list from the validator's last error, the listing's hidden reasons and the idle-pay reasons, and marks those nodes `"blocking_reasons_source": "cli_fallback"`.
- SDK: `ProviderClient.provider_overview()` (`GET /miners/overview`).
