### Security
- SDK SSH connections (`exec`, `stream_exec`, `rsync`) now pin each pod's host key on first use under `~/.lium/known_hosts/<pod-id>` and raise `LiumHostKeyError` when a pod later presents a different key, instead of accepting any key (`AutoAddPolicy`, `StrictHostKeyChecking=no`). `LIUM_SSH_INSECURE=1` restores the previous behaviour, with a warning naming the host and fingerprint (`SHA256:…`, as `ssh-keygen -lf` prints it) of every key accepted unverified. `reboot`, `edit`, `switch_template` and `rm` drop the pin, since each replaces the container.
