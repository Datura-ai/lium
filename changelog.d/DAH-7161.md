### Security
- Every `ssh` the CLI and SDK start (`lium ssh`, `lium up`, `lium rsync` and `Lium.rsync`, the kept SSH connection the SDK reuses for commands, and the pod-to-pod hop of `lium cp`) passes `-o ForwardAgent=no -o ForwardX11=no -o ForwardX11Trusted=no`, so a `ForwardAgent yes` or `ForwardX11 yes` line in `~/.ssh/config` never hands the local SSH agent or X display to a pod. The `ssh_command` that `lium ps --format json` and `lium describe` print carries the same options. File transfers also pass `-o ClearAllForwardings=yes`; `lium ssh` keeps the port forwards a user sets up in `~/.ssh/config`.
