### Added
- CLI: `lium describe <pod>` shows the pod's last lifecycle event (`Last event: REBOOT_FAILED (reboot_failed) — Container creation failed … (failure_step: ssh_connect) · <time>`) and the node's disk health (`Node disk: ok` / `PROBLEM — read-only: /var/lib/docker; write probe failed; 4 kernel I/O errors` / `unknown (not probed)`); `--json` carries `last_event` and `node_disk`. `lium describe <pod id>` of a pod that is no longer listed prints the events the backend kept for it — the delete, its reason, a failed reboot's cause — instead of "not found".
- CLI: `lium ps <pod>` prints `last event: …` under the table (and `last_event` in `--format json`); an unlisted pod's error points at `lium describe <pod id>`.
