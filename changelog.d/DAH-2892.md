### Added
- `lium templates` shows a `Runs on` column — the CUDA build, then the generations (`13.0 Hopper+Blackwell` / `Hopper only` / `pre-Hopper`) — derived from the image tag; `--arch hopper|blackwell` keeps only templates known to run on that generation (Blackwell needs CUDA 12.8+). `--format json` rows gain `cuda_version`, `torch_version` and `arch`.
