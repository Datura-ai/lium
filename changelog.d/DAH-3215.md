### Security
- `lium ssh` and the shell `lium up` opens now pin the pod's host key under `~/.lium/known_hosts/<pod-id>` (`StrictHostKeyChecking=accept-new`, as the SDK's `rsync` does) instead of passing `-o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null`; `LIUM_SSH_INSECURE=1` keeps the old behaviour. The OpenSSH command is an argument list built from the pod's user, address and port (`Lium.ssh_argv`) and runs without a shell; an `ssh_connect_cmd` of any other shape is refused with `ssh_unavailable` (exit 4). `Lium.ssh()` returns the shell-quoted form of that list (and creates the pod's empty pin file when there is none yet), so a key path with spaces no longer splits; the pin path is quoted so a home directory with a space stays one `UserKnownHostsFile`.
