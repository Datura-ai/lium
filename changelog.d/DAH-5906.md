### Added
- `lium workspaces login` works for accounts with two-factor sign-in on: after the password it asks for the code from the authenticator app or a recovery code, or takes it from `--totp-code` (`--code` still works; without a terminal the flag is required). The SDK raises `LiumTwoFactorRequired` from `workspaces.login()` and finishes with `workspaces.login_two_factor(mfa_token, code)`. API keys never need a code.
- `lium signup` sign-ins (reading back the API key, `--billing-key`) finish a two-factor challenge too: `--totp-code` answers the first ask, a terminal is asked after that, and a script without the flag gets an error naming it. A wrong code is reported as such.
