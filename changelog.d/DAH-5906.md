### Added
- `lium workspaces login` works for accounts with two-factor sign-in on: after the password it asks for the code from the authenticator app or a recovery code, or takes it from `--code` (without a terminal, `--code` is required). The SDK raises `LiumTwoFactorRequired` from `workspaces.login()` and finishes with `workspaces.login_two_factor(mfa_token, code)`. API keys never need a code.
