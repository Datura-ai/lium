### Added
- `lium reset-gpu <pod> [--gpu N ...]` and `Lium.reset_gpu(pod, gpu_indices=None)` reset a pod's hung GPUs without recreating the pod (`POST /pods/{id}/reset-gpu`). Every process in the pod is stopped, files are kept; the command asks first (`--yes` skips it), prints a result per GPU (`--json` for machine output) and exits non-zero with the API's code when the reset is refused (`mig_enabled`, `reset_not_supported`, `gpu_reset_unavailable`, ...) or a GPU failed.
