### Fixed
- `lium up -c N` and SDK `Lium.up(gpu_count=N)` on a node that splits only for a rent without Jupyter no longer refuse N as "rents whole only": a rent without Jupyter holds one port fewer, so it reads the listing's `min_gpu_count_for_ssh_only_rental` (SDK `ExecutorInfo.whole_host_only_ssh_only`); `--jupyter` / `enable_jupyter=True` reads `min_gpu_count_for_rental` (`whole_host_only`) as before. An API without the new field falls back to the old one.
