### Security
- The SDK follows an HTTP redirect only to the same scheme, host and port. `requests` drops only `Authorization` on a cross-host redirect, so `X-API-KEY` and a 307/308 body were re-sent to whatever host a `Location` named; such a redirect now raises `LiumError` instead. (ticket-0260 report 7)

### Fixed
- `lium provider node list`, `machine-requests`, `billing`, `node get` and the other provider tables show a bracketed GPU name, machine name or id as text; `[/]` in a value from the portal used to raise `MarkupError` and end the listing without a table, and `[red]` vanished from what was shown.
