### Fixed
- `lium workspaces login` works on a server without workspaces (lium.io today), so `lium keys list/create/show/budget` can use the session there. Before, the login was refused with "Workspaces are not enabled on this server" while every `lium keys` command told you to run it. On such a server `lium keys` manages the account's own keys. `lium keys create --save` exits 2 there, because `--save` keeps a key for `--workspace`; set the key with `lium config set api.api_key <key>` instead.
- `lium signup` no longer saves a masked billing key as the CLI's API key. `GET /keys` lists a billing key as a prefix plus a mask (`key_retrievable: false`), and that string got 401 on every call. Keys without the `rent` scope are skipped too.
